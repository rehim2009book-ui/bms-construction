# BMS Construction LLC — website preview

Review copy of the BMS Construction LLC website, served by GitHub Pages at https://rehim2009book-ui.github.io/bms-construction/

It differs from the site files only in the `<head>` of `index.html`: it carries `<meta name="robots" content="noindex">`
so search engines skip it, and its canonical, `og:url`, `og:image` and `twitter:image` point at this preview address
instead of https://bms.com.az/. Undo both before these files become the live site.
